## Pass 1: premise and canon check (before writing)
- **Same year as File 001:** Day 0 at 1:52 PM Manila is File 001's 6:52 AM at UTC+1 (05:52 UTC), and Day 365 at 1:52 PM likewise. Tomás is File 001's bus-stop boy, kept at the same stop and the same times.
- **Weekday fix:** File 001 draws a yellow school bus, so Day 0 can't be a Saturday. It is now Monday 15 June 2026, the first day of the Philippine school year, a half day.
- **Perseids:** with that date they peak on the night of 12–13 August, Day 58/59.
- **Satellites:** solar-powered satellites die within hours, and File 001 never uses one after Day 0. Added to the File 001 world model as an explicit rule.
- **Cold:** Manila is surrounded by warm sea, so it cools more slowly than File 001's city. It is above freezing until about Day 30, which keeps File 001's −45 °C Day 365 shot (the boy in winter gear) consistent.
